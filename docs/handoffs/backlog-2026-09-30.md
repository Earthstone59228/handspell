## Working rules
- Read `.coord/PROTOCOL.md`. Claude orchestrates and Codex executes via `.coord/BOARD.md`. Codex is **paused** (the
  owner is switching it to API billing). The owner is also happy for a cheaper Sonnet subagent to do bulk work.
- **Design language:** `AslButton`, `LocalAslColors`, `Spacing`, `AslShapes`, `FrostedSettingsHero` (takes a title,
  body, optional back), `SettingsGroup` and the `Settings*Row` family. No raw Material defaults. The web menu source
  of truth is `web/`: build with `cd web && npm ci && npm run build -- --base=./`, then run
  `scripts/sync-ionic-frontend.sh web/dist`.
- **Gate:** `cd android && source ../env.sh && ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`
  (127 tests, 0 lint errors at `cbec4cf`).
- **Device:** Galaxy S25 Ultra over USB (`adb devices` → SM_S938B). **Never touch the Tab S10 (SM_X926B)**, which
  belongs to another project. Screenshots are 1440x3120, and tap coords = displayed × 1.56.
- Before committing, secret-scan the staged diff against the key in `android/local.properties`. Count only, never
  print it.
- Gotchas:
  - `pkill -f <pattern>` inside a Bash call can match its own command line and kill it. Use PIDs.
  - MediaPipe in Python needs the desktop env vars stripped (see `training/scripts/smoke_landmarker.py`).
  - Use `spawn` for process pools.
  - The `hf download` CLI silently applied only the last of several `--include` patterns.
