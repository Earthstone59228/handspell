# Shipaton Next Gen demo video

`handspell-shipaton-submission.mp4` is the 1:58 English demonstration cut. It covers the story behind Handspell, letter and word practice, speed and streaks, Pro access, RevenueCat integration, on-device ML, and the public source repository.

The opening includes a real camera practice view recorded from the connected Android phone. No signer or successful recognition is shown because a usable live-hand recording was unavailable. The word-reference animation is app content, not captured camera footage. The Pro screens shown after the paywall are unlocked by a separate local three-day demo trial, not by a completed Test Store purchase. Test Store purchases in this build are simulated and charge no money.

This file is ready for review. The Shipaton rules require the submission video itself to be publicly visible on YouTube or Vimeo; adding this file to GitHub does not satisfy that upload requirement.
